# CodeAlpha_PhishingAwareness

Phishing Awareness Training presentation created by **Thabo Machume** for **Task 2** of the CodeAlpha Cyber Security Internship.

## About

A 10-slide training module that teaches people how to recognise and avoid phishing attacks.

## Topics covered

1. Introduction
2. What is phishing?
3. Social engineering tactics (urgency, authority, fear, curiosity)
4. Common types of phishing (email, spear phishing, whaling, smishing, vishing)
5. Spotting a phishing email (red flags)
6. Spotting a fake website (lookalike domains, the HTTPS myth)
7. Real example: the 2017 Google Docs phishing attack
8. Best practices to protect yourself
9. Quick quiz
10. Key takeaways
